# ⚡ Blinkit Sales Analytics Dashboard

An interactive **Power BI dashboard** built to analyze sales performance, product categories, and outlet trends for **Blinkit – India's Last Minute App**.
The dashboard helps explore key metrics like total sales, outlet performance, and product demand to support data-driven decision making.

---

# 📌 Purpose

The **Blinkit Sales Dashboard** provides insights into sales distribution across item types, outlet locations, and outlet types.
It enables users to quickly understand which products and outlets contribute the most to overall sales.

---

# 🛠 Tech Stack

* **Power BI Desktop** – Used for creating the interactive dashboard
* **Power Query** – Data cleaning and transformation
* **DAX (Data Analysis Expressions)** – Creating measures and KPIs
* **Data Modeling** – Relationships between sales, items, and outlet attributes
* **File Format** – `.pbix` for development and `.png` for dashboard preview

---

# 📊 Data Source

The dataset contains retail sales information including:

* Item Type
* Item Fat Content
* Outlet Location Type
* Outlet Establishment Year
* Outlet Size
* Item Visibility
* Item Rating
* Total Sales
* Outlet Type

This structure allows analysis across **products, outlets, and sales performance metrics**.

---

# 🚀 Dashboard Highlights

## Key KPIs

* **Total Sales:** 1.20M
* **Number of Items:** 8523
* **Average Sales:** 141
* **Average Rating:** 3.9

## Key Visuals

* **Sales Trend by Outlet Establishment Year** – Shows how outlets contribute to sales over time
* **Item Type Sales Analysis** – Identifies top-performing product categories
* **Outlet Location Tier Analysis** – Compares sales across Tier 1, Tier 2, and Tier 3 outlets
* **Fat Content Distribution** – Compares Low Fat vs Regular product sales
* **Outlet Type Comparison** – Shows performance of Grocery Stores and Supermarkets

---

# 📈 Key Insights

* **Tier 3 outlets generate the highest sales contribution.**
* **Supermarket Type 1 dominates overall sales.**
* Product categories like **Fruits, Snacks, and Household items lead sales.**
* The **average customer rating is around 3.9 across outlets.**
