An interactive "Power BI dashboard" designed to analyze sales performance, outlet characteristics, and product trends for Blinkit – India's Last Minute App. The dashboard enables quick exploration of sales patterns, product performance, and outlet-level insights to support data-driven decision making.

---

📌 Purpose

The "Blinkit Sales Analytics Dashboard" is a dynamic Power BI report built to analyze sales data from Blinkit outlets.
It helps users explore key metrics such as total sales, product category performance, outlet distribution, and customer ratings.

The dashboard is designed for "business analysts, retail managers, and data enthusiasts" who want to understand how product categories, outlet types, and locations impact overall sales performance.

---

🛠 Tech Stack

The dashboard was built using the following tools and technologies:

• 📊 "Power BI Desktop" – Main platform used for creating interactive dashboards and visualizations.
• 📂 "Power Query" – Used for data cleaning, transformation, and preparation.
• 🧠 "DAX (Data Analysis Expressions)" – Used for calculated measures such as Total Sales, Average Sales, and KPIs.
• 🧩 "Data Modeling" – Relationships created between dataset attributes such as item type, outlet size, and location.
• 📁 "File Format" – `.pbix` for Power BI development and `.png` for dashboard preview.

---

 📊 Data Source

The dataset represents retail sales information for Blinkit grocery outlets.

The dataset includes attributes such as:

• Item Type
• Item Fat Content
• Outlet Location Type
• Outlet Establishment Year
• Outlet Size
• Item Visibility
• Item Rating
• Total Sales
• Outlet Type

The dataset is structured to allow analysis across "products, outlets, and sales performance metrics".

🚀 Features / Highlights

# Business Problem

Retail businesses generate large volumes of sales data, but it is often difficult to quickly identify:

• Which product categories generate the highest revenue
• Which outlet locations perform better
• How outlet types influence sales performance
• Trends in outlet establishment and growth

Without visualization, extracting these insights from raw data becomes time-consuming.

---

# Goal of the Dashboard

The goal of this dashboard is to create an "interactive business intelligence tool" that:

• Provides a quick overview of Blinkit sales performance
• Helps analyze product category contribution to total sales
• Compares outlet performance across different location tiers
• Identifies trends related to outlet establishment and growth
• Supports better business decision making through visual insights

## Business Insights

• Tier 3 outlets generate the highest overall sales.
• Supermarket Type 1 contributes the majority of total revenue.
• Product categories like "fruits, snacks, and household items dominate sales.
• Customer ratings remain consistent across outlet types (~3.9 average rating).

These insights can help businesses "optimize product distribution, store strategy, and regional expansion.
